# Mutation Worlds — Visual Theme Lab

Interactive comparison of six biological skins for the four germ mutations:

1. Swap — exchange factor order and retain the parity sign.
2. Shape — move between flat and nested presentations.
3. Viccheda — dissect at a seam and retain the borrowed scalar.
4. Sandhi — match, release the overlap scalar and keep the residual germ.

## Open

Run the game server from `game/`:

```bash
python3 -m http.server 8765
```

Then open:

```text
http://localhost:8765/docs/visual/index.html
```

## Worlds

- **Seam phage** — strongest complete creature/game fantasy.
- **Sticky-end lab** — clearest visual teaching language.
- **Segmented virus** — strongest swap and swarm/cascade behavior.
- **Recombination** — strongest shared-seam biological story.
- **Fold creature** — strongest shape-change animation.
- **Jumping gene** — strong cut, orientation and insertion actions.

The displayed ratings are design heuristics, not scientific measurements.
Every biological option is a visual interpretation; none should be described as
literally computing geometric-algebra or Capelli identities.
