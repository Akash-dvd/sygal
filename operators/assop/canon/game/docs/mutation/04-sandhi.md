# Mutation 4 — Sandhi

Sandhi merges compatible germs after their pins, grades, tree shapes and shared
seams pass the engine's gates. The overlap becomes a scalar; the unconsumed
structure becomes one residual germ.

## Vector-only domain

All atomic symbols are grade-1 vectors. Multi-vector pins and seams, when they
appear in a flattened expression, are ordered blades constructed from those
vectors. The game does not use opaque general versors as atoms.

## Symbolic example — one-vector seam

```text
L = d ⌋ (A ∧ B)
R = d ⌋ (B ∧ C)
```

The pin and shape match, and `B` is the shared seam:

```text
L ∧ R
  =
(d | B) · (d ⌋ (A ∧ B ∧ C))
```

Game result:

```text
consumed germs: L, R
scalar gained:  (d | B)
residual germ:  d ⌋ (A ∧ B ∧ C)
```

## Symbolic example — sign carried from a mutation

After reversing the second panel:

```text
d ⌋ (C ∧ B) = −d ⌋ (B ∧ C)
```

the merge carries that coefficient:

```text
(d ⌋ (A ∧ B)) ∧ (−d ⌋ (B ∧ C))
  =
−(d | B) · (d ⌋ (A ∧ B ∧ C))
```

Sandhi must never discard the sign introduced by Swap or order reversal.

## Symbolic example — multi-vector seam

Let the shared seam be:

```text
S = B₁ ∧ B₂
```

Schematic merge:

```text
(D ⌋ (A ∧ S)) ∧ (D ⌋ (S ∧ C))
  =
Capelli(D, S) · (D ⌋ (A ∧ S ∧ C))
```

`Capelli(D, S)` denotes the determinant-like overlap produced by the engine.
Its exact form and parity depend on the grades and contraction convention.

## Nested symbolic example

Two compatible towers:

```text
d₁ ⌋ (A₁ ∧ (d₂ ⌋ (B₁ ∧ S)))

d₁ ⌋ (A₂ ∧ (d₂ ⌋ (S ∧ B₂)))
```

can merge from their common inner seam:

```text
overlap(d₁ ∧ d₂, S)
  ·
d₁ ⌋ ((A₁ ∧ A₂) ∧
  (d₂ ⌋ (B₁ ∧ S ∧ B₂)))
```

This is schematic notation for the recursive Sandhi pattern. The precise
normal form must be generated by `SandhiCanon`.

## Failure and zero cases

Different pins or incompatible contexts do not merge:

```text
(d₁ ⌋ (A ∧ B)) ∧ (d₂ ⌋ (B ∧ C))
  → no Sandhi match
```

A repeated factor in the residual wedge annihilates it:

```text
d ⌋ (A ∧ B ∧ A) = 0
```

A grade mismatch may also make the contraction zero:

```text
grade gate x > 0  →  0
```

## Game operation

1. Select two germs.
2. Normalize or compare their shapes.
3. Check matching pin lineage, grade gate and shared seam.
4. Multiply their existing coefficients and signs.
5. Compute the overlap/Capelli scalar.
6. Consume any matching Viccheda scalar-debt token.
7. Replace both inputs with the engine-produced residual germ.
8. Clear the result if alternation or the grade gate produces zero.
9. Trigger a cascade if the residual germ matches another neighbour.

## Boundary

Visual similarity is not sufficient. `SandhiCanon` is the source of truth for
whether a merge exists and for its residual tree, coefficient, parity and
Capelli factor.
